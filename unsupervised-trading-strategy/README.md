# Unsupervised Learning Trading Strategy

An end-to-end quantitative trading project that applies unsupervised machine
learning to construct and backtest portfolios of S&P 500 stocks.

## Planned Pipeline

1. Collect historical S&P 500 market data
2. Engineer technical and momentum features
3. Estimate factor exposures
4. Cluster stocks using K-Means
5. Generate stock-selection signals
6. Construct optimized portfolios
7. Backtest the trading strategy
8. Compare performance against a benchmark

## Tech Stack

- Python
- Pandas / NumPy
- yfinance
- scikit-learn
- statsmodels
- PyPortfolioOpt
- pandas-ta
